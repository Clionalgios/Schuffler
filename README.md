# README : Schuffler

Schuffler est un outil de transformation de chaînes de caractères, basique et extensible. Il est décliné en plusieurs langages, chacun compilable et opérable individuellement sans faire usage des autres sources du projet.

## Compilation

La méthode pour compiler Schuffler dépend de l'environnement que vous voulez utiliser. La commande à appliquer sera indiquée dans le README inclut dans chaque version linguistique du projet. Notez que dans tous les cas, il faudra exécuter la commande de compilation depuis le répertoire racine du projet.
